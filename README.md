# Jigit Barbershop

Сайт барбершопа Jigit — Бишкек, ул. Щербакова 57.

## Запуск локально

```bash
npm install
npm run dev
```

## Деплой

Сайт автоматически деплоится на GitHub Pages при пуше в `main`.

URL: `https://yormungand520.github.io/barbershop-zhigit/`

## Технологии

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- GitHub Pages
